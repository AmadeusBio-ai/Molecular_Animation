# References

Put reference clips and images for a brief here: a look to match, a motion to study, a brand mark. Scripts never read them; they are for your eyes and for measurements like silhouette IoU, colour medians and motion statistics (`pipeline.py motion`).

Everything in this folder except this README is ignored by git. Reference material usually belongs to someone else, so don't commit or redistribute it unless you hold the rights. Describe each reference in the project's `brief.md` instead: where it came from, what to match (look, motion, timing), and what not to copy.
