# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults and personal or political attacks are not acceptable in issues, pull requests, discussions or any other project space.

To report unacceptable behaviour, contact the maintainers of the [AmadeusBio-ai](https://github.com/AmadeusBio-ai) organisation privately (for example through GitHub's private vulnerability and abuse reporting), or open an issue asking a maintainer to get in touch. Reports are handled confidentially. Maintainers may remove contributions or block contributors who break this code, as described in the Covenant's enforcement guidelines.
